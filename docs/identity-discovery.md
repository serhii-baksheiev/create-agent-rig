## Reading the gaps (findings, not proposals)

- **agent** is the only axis with a `none` in the rig, and **task** the only one
  with a `none` in memory. Everything else has _an_ identity; what differs is
  the shape (bare string vs. delimited JSON key vs. tracker key).
- **session** is hashed in memory (64-hex), raw in the bus (`instanceId` is
  whatever the caller passes) and absent in the rig (the run directory stands
  in). Any join across the three would have to agree on _which_ of these is the
  session.
- **version** exists on the memory event and the rig manifest, and on nothing
  the bus sends.
