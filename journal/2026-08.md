# Journal — 2026-08

The human journal for August 2026. **Newest first** — a new entry goes directly
under this heading, so the file reads as a stack and the order carries the
sequence. Entries are date-free by design; the month is the filename's job.

One file per month, `journal/YYYY-MM.md`. The convention and the field list live
in `templates/agent-os/universal/journal/README.md`, which is the copy a
generated project gets.

🔴 **This is not `.claude/runs/*/events.jsonl`.** That one is the machine trace —
append-only, oldest-first, written by `run-journal.mjs`. This file is the human
record, newest-on-top, written by a session at its checkpoints and stops. Reading
one as the other is how a reader concludes the run did nothing.
